## Проверка подключения к PostgreSQL

SQL-файл `db/smoke_test.sql` проверяет подключение к БД, создаёт тестовую таблицу, записывает строку `LR8 connection OK` и считывает её обратно.

Перед запуском задаются параметры подключения:

- `PGHOST` — адрес сервера PostgreSQL;
- `PGPORT` — порт PostgreSQL;
- `PGDATABASE` — имя тестовой БД;
- `PGUSER` — пользователь БД;
- `PGPASSWORD` — пароль пользователя.

Запуск в PowerShell:

```powershell
.\scripts\check-postgres.ps1
```

Результат выполнения сохраняется в `evidence/smoke-test.txt`.
